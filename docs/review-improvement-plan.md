# 복습 페이지 개선 검토 및 구현 계획

검토일: 2026-10-24. 코드 검토와 기존 practice 테스트 47개 통과를 기준으로 작성했다. 실제 로그인 브라우저 검증과 DB 장애 실험은 아직 하지 않았다. 이 문서는 계획이며 제품 코드 변경을 의미하지 않는다.

## 목표와 유지할 계약

- 추천 이유와 이번 세션 분량을 명확히 하고, 설정 없이 기본 10개로 시작할 수 있게 한다.
- 복습 대기 수, 선택 가능한 문제 수, 이번 세션 수, 첫 시도 정답 수를 구분한다.
- 기존 번들 완료·스타·단어 숙련도 의미를 유지한다. 일반 단어 복습은 번들별 완료 ID를 추가하지 않는다. 문장 복습의 기존 원본 번들 연결 및 Word Fill의 연관 단어 효과는 유지하되 중복 집계하지 않는다.
- `scope=unstarted`의 신규 학습과 `bundleSession`의 번들 연습은 복습 전용 변경으로 영향을 받지 않아야 한다.
- 첫 배포에서는 숙련도 산식, 1/7/15/30일 간격, 숙련도 5 제외 정책을 바꾸지 않는다. 장기 복습 정책은 데이터 측정 후 별도 변경한다.

## 추가 검토 결과

1. **저장 재시도의 중복 반영**: 현재 POST에는 시도 ID가 없고 숙련도/정오답을 증가시킨다. 응답만 유실된 경우 재전송하면 두 번 반영될 수 있다. 여러 테이블을 순차 갱신하며 문장 숙련도 저장 오류를 로그만 남기는 경로도 있다. 클라이언트 `response.ok` 확인만으로 해결되지 않는다.
2. **즉시 재학습과 새 복습의 혼동**: 완료 후 재시작은 기존 props의 후보를 재사용한다. 문장 공통 클라이언트의 다시 풀기는 새 결과를 기록할 수 있다. 첫 시도와 같은 세션의 재연습을 구분해야 한다. 단어 스펠링의 현재 재시도 제외 동작은 보존한다.
3. **모드별 유효 대상 불일치**: 문장 Word Fill은 연결 단어가 없으면 임의 단어를 만들지만 API는 유효한 word_id와 대상 관계를 요구한다. 랜덤 대상 선택도 렌더 과정에 있다. 모드 적합성 검증 후 개수를 정하고, 세션 생성 시 대상 단어를 고정해야 한다.
4. **문장 퀴즈의 선택지 부족**: 후보가 한 개이거나 번역이 모두 같으면 정답만 있는 퀴즈가 가능하다. 독립된 선택지 풀 또는 유효한 대체 모드를 사용한다. 단어 퀴즈의 고정 일반 단어 오답도 품질 측정 대상이다.
5. **플래시카드 정책**: 문장 플래시카드는 registry상 무채점 열람 모드다. 저장 누락 버그로 간주해 정답 API에 연결하지 않는다. 우선 '다시 보기 · 복습 일정에 반영되지 않음'으로 구분한다. 단어 플래시카드의 기존 자기평가는 별도 유지한다.
6. **추천 우선순위**: 현재 유형 추천은 개수 우선, 항목은 숙련도/누적 오답 우선이며 클라이언트에서 다시 섞는다. 오래 기다린 항목이 계속 밀릴 수 있다. 추천과 세션 대상은 하나의 결정 규칙을 사용해야 한다.
7. **수량과 일정 표현**: summary의 유형별 제한 20, 페이지 로드 상한 40, 기본 선택 10이 혼재한다. 오답도 다음 날로 이동하므로 대기 수 감소를 '모두 기억함'으로 표현하면 안 된다. nextReviewAt은 현재 정책 대상의 다음 예정 시각이며 전체 학습의 완전한 미래 일정은 아니다.
8. **빈 상태와 오류**: 미학습/다음 복습 대기/접근 가능한 대상 없음/조회 실패는 다르다. 조회 실패를 0개로 처리하지 않는다. 일부 접근 제한 정보는 현재 응답으로 구분할 수 없으므로 추가 데이터 없이는 단정적인 문구를 쓰지 않는다.
9. **인증 경로**: 복습 페이지는 `/auth/sign-in`을 사용하지만 로컬 라우트는 `/auth/login`이다. `/learn/*`는 미들웨어 공개 경로여서 페이지의 잘못된 리다이렉트를 대신 고쳐주지 않는다.
10. **조회 비용**: 현재 요약도 오답 후보·문장 매핑·학습 이력을 모두 읽는다. 버튼이나 렌더마다 요약 전체를 반복 호출하지 않는다. 경량 요약과 세션 상세를 단계적으로 분리하고 사용자 간 공유 캐시는 만들지 않는다.

## 구현 순서

### 1. 복습 후보·추천·세션 계약 정리

대상: `lib/learning/review-recommendation.ts`, 신규 `lib/learning/review-session.ts`, `lib/supabase/services/learning-review.ts`, `lib/practice/registry.ts`의 대상 검증 재사용.

- 추천 응답을 `{ type, mode, count, reason }`으로 정의하고 대기 총량은 별도 유지한다. 기존 learn 홈/진행 화면 호출도 함께 맞추거나 호환 래퍼를 유지한다.
- 정책 상수: 기본 10, 선택 5/10/20, 1회 로드 최대 40. 전체 선택은 실제 모든 대상이 로드된 경우에만 제공한다.
- 후보 선정 순서: 접근/콘텐츠 검증 → 복습 시점 확인 → 모드 적합성 확인 → 우선순위 정렬 → N개 선택 → 선택된 N개의 출제 순서 섞기.
- 최초 우선순위는 예정 시각 오름차순, 최근 오답 여부, 낮은 숙련도, 안정적 ID 순서로 정한다. 검증되지 않은 가중 점수는 도입하지 않는다. 예정 시각이 없는 시작된 항목은 별도 '첫 복습' 그룹으로 명시하고 무한 연체로 계산하지 않는다.
- 유형 추천도 각 유형의 최우선 후보를 같은 규칙으로 비교한다. 동일하면 대기 수, 고정 유형 순서로 결정한다. 모든 유형이 유효한 기본 모드를 갖는지 확인한다.
- Word Fill은 `getWordFillMapCandidates`와 같은 규칙을 사용하고 fallback 임의 word_id를 제거한다. 세션 생성 때 word_id/문항/선택지를 고정한다.
- 정답만 있는 문장 퀴즈는 시작하지 않는다. 검증된 선택지 풀이 없으면 스크램블을 추천하고 변경된 모드를 표시한다.

완료 기준: 추천에 표시한 개수·모드가 실제 출제와 일치하고, 상위 후보가 랜덤 추출로 빠지지 않으며, 신규 학습/번들 연습 선택 규칙은 유지된다.

### 2. 저장 신뢰성 확보 — 자동 재시도의 선행 조건

대상: 결과 API, `bundle-progress.ts` 저장 서비스, 신규 시도 저장 마이그레이션/RPC, 공통 결과 전송 모듈.

- 복습 시도마다 `sessionId`, `attemptId`, 항목 ID, 모드, 최초 답을 고정한다. 인증 사용자와 서버가 검증한 대상에 결합한다. 재전송할 때 새 ID를 만들지 않는다.
- 사용자+attemptId 유일 제약과 입력 일치 검증으로 중복 요청을 처리한다. 같은 ID에 다른 답을 보낸 경우 거절한다. 동일 세션 항목의 첫 평가를 서버에서도 한 번만 허용한다.
- 이벤트 기록과 핵심 숙련도/문항 기록을 한 DB 트랜잭션으로 반영한다. 연관 단어 효과, 스타, 통계, 일일 활동까지 원자 처리하거나 이벤트 ID를 기준으로 안전하게 재처리 가능한 구조로 만든다. 단순한 '중복 방지 행 INSERT 후 기존 여러 API 호출'은 부분 실패를 해결하지 못하므로 사용하지 않는다.
- 동시 요청의 read-modify-write 충돌을 행 잠금/원자 갱신으로 방지한다. 트랜잭션 안에서 학습 상태 갱신과 최초 평가 여부 검증을 한다.
- 기존 앱 클라이언트의 payload는 호환 유지한다. 새 복습 경로부터 새 저장 계약을 사용한다. 서버에서 사용자·번들 접근·항목 관계·허용 모드를 다시 검증한다.
- 클라이언트는 `pending/saved/failed`를 표시한다. 정오답 피드백은 즉시 보여주되 미저장 상태를 완료로 확정하지 않는다. 다음 세션 이동 전에 미저장 건을 처리한다. 네트워크 재전송과 다시 풀기는 다른 동작이다.
- DB 변경이 준비되기 전에는 자동 재시도 기능을 출시하지 않는다. 기존 문장 저장 오류를 숨기는 경로도 함께 정리한다.

완료 기준: 서버 반영 후 응답 유실, 중복 클릭, 병렬 요청, 중간 DB 오류에서 숙련도·스타·정오답·일일 활동이 중복 또는 부분 반영되지 않는다. RPC는 실제 임시 DB에서 검증한다.

### 3. 세션 진행·완료 흐름 통일

대상: `SentencesReviewClient.tsx`, `WordPracticeClient.tsx`, 공통 문장 연습 컴포넌트의 선택적 완료/저장 인터페이스, 신규 복습 완료 UI.

- 공통 연습 컴포넌트는 optional callback/result slot으로 확장한다. 번들 연습에서 사용하는 기존 기본 동작은 유지한다.
- 세션에서 첫 시도 결과, 정답 공개, 건너뜀, 미제출, 저장 상태를 항목별로 관리한다. 정답 공개는 기존처럼 실패로 처리하고 미제출·건너뜀은 자동 정답으로 만들지 않는다.
- 완료 요약의 분모와 첫 시도 정답 수를 일치시킨다. 즉시 다시 보기는 원래 오답을 덮어쓰거나 숙련도/스타/집계를 추가하지 않는 재연습으로 처리한다.
- 저장 완료 후 최신 대기 상태를 재조회한다. '다음 10개'는 기존 배열 재사용 없이 새 후보로 시작한다. 다른 탭에서 처리되거나 삭제된 항목 때문에 수량이 달라지면 최신 수량을 보여준다.
- 문장→단어 및 단어→문장 연결을 양방향 지원한다. 기존 nextTo는 허용된 로컬 경로만 받고 최신 대상이 0이면 버튼을 숨기거나 최신 추천으로 대체한다.
- 완료 화면에는 '이번 세션 완료', 첫 시도 정답, 다시 볼 오답, 남은 대기 수를 표시한다. 오답이 내일로 이동한 것을 학습 숙달로 표현하지 않는다.
- 신규 학습은 기존 returnTo와 scope를 유지한다. 복습 세션의 제외/재연습 규칙을 번들 연습에 무조건 적용하지 않는다.

완료 기준: 다음 세션에 방금 처리한 항목이 stale props 때문에 재등장하지 않고, 같은 세션 재연습이 평가를 중복 반영하지 않으며 양방향 이동이 작동한다.

### 4. 복습 메인 화면 및 진입 경로 개편

대상: `/learn/review/page.tsx`, 문장/단어 page, 신규 추천 카드·빈 상태·오류/로딩 UI.

- 상단 추천 카드에 이번 세션 분량·모드·사실에 맞는 추천 이유·바로 시작 버튼·설정 변경을 배치한다. 전체 대기 수는 보조 정보, 유형별 선택은 그 아래 둔다.
- 바로 시작 URL은 mode/count/start의 허용 값만 해석하며 서버의 실제 후보 개수로 다시 제한한다. URL 접근/프리패치만으로 기록이나 평가를 만들지 않는다. React 재렌더/Strict Mode에서 세션이나 제출이 중복 생성되지 않게 한다.
- 미학습과 미래 복습 대기는 검증 가능한 요약 필드로 구분한다. 다음 시각은 사용자 시간대 기준으로 표시하고 서버 시각과 브라우저 시각 차이로 hydration 오류가 나지 않게 한다. 오늘/내일 경계 테스트를 추가한다.
- 인증은 `/auth/login`으로 통일하고 검증된 설정을 포함한 redirectTo를 보존한다.
- 조회 실패는 재시도 가능한 오류 상태로, 대기 조회는 로딩 상태로 표시한다. 화면 초점·상태 안내·키보드 조작·선택 상태(`aria-pressed`)도 포함한다.
- 320/375/768/1024/1280px, 한국어/영어, 다크 모드에서 버튼과 긴 문구가 넘치지 않게 확인한다. 숫자 반복과 고정 3열 배치는 피한다.

완료 기준: 모바일에서도 핵심 CTA가 명확하고, 추천 바로 시작/설정 변경/로그인 복귀/빈 상태/조회 오류 흐름이 연결된다.

### 5. 성능·검증·출시

- 후보 정책을 공통화한 뒤 요약용 조회에서 문항 상세/오답 후보를 분리한다. 세션에서 필요한 항목만 상세 로드한다. DB row cap을 넘는 페이지 순회와 접근 권한 검증을 유지한다.
- 복습 조회 실패율, 결과 저장 실패율, 시작→완료 비율, 다음 예정 복습의 첫 시도 정답률을 측정한다. 답안·문장 원문 대신 최소 이벤트 메타데이터를 사용한다. 즉시 재연습 점수와 단어 자기평가를 객관식 정답률과 합치지 않는다.
- 기존 `tests/practice.test.mjs`에 추천/출제/저장 계약 테스트를 추가한다. 필요한 경우 복습 전용 파일로 분리한다. TypeScript/ESLint/기존 전체 테스트를 실행한다.
- 회귀 항목: Word Fill 연관 단어 효과 한 번, 일반 단어 복습의 번들 완료 불변, 무채점 문장 플래시카드, scope=unstarted, 기존 번들 연습, 두 언어 fallback, 0/1/9/10/40/41개, 동일 번역, 누락 매핑, 비공개/접근 불가, 시각 경계, API 오류, 중복/동시 제출.

## 첫 배포에서 제외할 항목

- 숙련도 5 자동 재편입, 복습 간격 알고리즘 교체, 개인별 예측 모델.
- 문장 플래시카드 자기평가의 신규 숙련도 정책.
- 문장·단어 혼합 세션과 오프라인 장기 재전송 큐.
- 데이터 없는 예상 소요시간 및 학습 효과 향상 수치.
