# 번들 완료 기준

- 문장 완료: 참여 가능한 문장 퀴즈·스크램블·단어 채우기의 스타를 모두 획득.
- 단어 완료: 실제 단어 프랙티스 대상 단어를 이 번들에서 모두 한 번 이상 맞힘. `user_bundle_interactions.metadata.completed_word_ids`에 기록하며, 단순 열람은 포함하지 않음.
- 전체 완료: 제공되는 학습 영역을 모두 완료. 문장만 또는 단어만 있는 번들은 해당 영역만 완료하면 됨. 학습 대상이 전혀 없으면 완료가 아님.
- 전체 진행률은 제공되는 영역별 달성률의 평균. 상단 스타 달성률과 스타 정렬은 문장 스타만 사용.
- 완료 후 오답이 나와도 획득 스타와 누적 정답 기록은 유지되므로 완료를 취소하지 않음. 콘텐츠를 추가하거나 학습 대상을 변경하면 현재 대상에 맞게 다시 계산됨.

## 데이터와 저장

`lib/practice/bundle-completion.ts`가 공통 계산 함수이며, 서버의 `loadBundleCompletion`은 실제 프랙티스와 같은 대상 선정 함수를 사용한다. `bundle_words` 선택과 단어 ID 중복 제거도 반영한다.

단어 학습은 `user_word_interactions`의 사용자·단어별 기록을 공유한다. 다른 번들이나 일반 단어 복습의 기록은 숙련도와 이전 학습 이력 표시에만 반영하며, 현재 번들 완료로 인정하지 않는다. 사용자 기록은 항상 해당 `user_id`로 제한한다.

`user_bundle_item_interactions.is_completed`는 기존 문장 최초 정답 통계용 의미를 유지한다. 이를 번들 전체 완료 계산에 사용하지 않는다.

`user_bundle_interactions.is_completed`, `progress_ratio`, `completed_at`은 전체 완료의 저장 스냅샷이다. 문장·단어 풀이 시 현재 번들만 갱신한다. 다른 번들의 완료 상태와 최근 학습 시각은 바꾸지 않는다. 단어 채우기에서 맞힌 단어도 현재 번들의 완료 ID에 포함한다.

조회는 저장 스냅샷을 신뢰하지 않고 학습 이력으로 다시 계산한다. 따라서 과거 완료 플래그가 남아 있거나 콘텐츠가 바뀌어도 목록·상세·홈의 판정은 동일하다. 기존 DB 전체를 일괄 수정하는 마이그레이션은 실행하지 않는다. 과거 `completed_at`으로 새 기준의 정확한 역사적 완료 시점을 보장할 수는 없다.

## 화면

상태 필터: 전체 / 학습 중 / 문장 완료 / 단어 완료 / 전체 완료 / 시작 전.
문장 완료와 단어 완료 필터는 전체 완료 번들도 포함한다. 학습 중은 부분 완료를 포함하되 전체 완료는 제외한다.

검증: `node tests/practice.test.mjs`, `npm test`, `npx tsc --noEmit --incremental false`.

## 번들별 단어 기록과 청취

완료 ID는 중복을 제거하며 현재 학습 대상과 대조한다. 과거 번들별 기록이 없으면 0부터 시작하고, 기존 공통 단어 숙련도는 보존한다. 새 테이블·컬럼·DB 함수는 추가하지 않는다.

JSON 기록은 현재 metadata 전체 값으로 조건부 UPDATE(compare-and-swap)를 수행한다. 다른 저장이 먼저 반영되면 다시 조회·병합하며 최대 8회 재시도 후 오류를 반환한다. 무조건 덮어쓰지 않으며 metadata의 다른 키를 보존한다.

단어 연습 기본 선택은 전체이다. 미완료는 해당 번들의 완료 ID로 계산하고, 모드별 맞힌·틀린 항목은 기존 공통 이력임을 화면에서 명시한다.

청취 시작 여부는 해당 번들의 현재 문장에 대한 play_count로만 판단한다. 공유 단어 이력·프랙티스 정답·저장된 위치만으로 청취 중으로 표시하지 않는다. 저장된 위치는 실제 청취 기록이 있을 때 이어서 듣기의 위치로 사용한다.

## 학습 홈 카드

`getHomeBundleLearning`이 공통 완료 결과에서 홈 카드용 문장 스타·번들별 단어 완료·누적 청취 및 학습 버튼을 만든다. 청취 기록이 없으면 듣기 시작, 기록이 있으면 실제 청취 위치로 이어서 듣기, 문장 연습을 마치고 단어만 남았으면 단어 연습을 안내한다. 단어만 있는 번들은 단어 연습으로 이동한다.

빠른 연습은 실제 가능한 모드만 표시하고 미완료 영역을 우선한다. 완료한 영역도 복습할 수 있다. 탐색 카드의 문장 수는 실제 문장 항목, 단어 수는 프랙티스 대상 단어를 중복 제거한 수이다. 과거 공유 단어 완료로 저장된 플래그만으로 신규 번들을 추천에서 제외하지 않는다.

홈 카드에는 전체 진행률 바와 퍼센트를 표시하지 않는다. 완료 배지·영역별 수치·학습 버튼을 표시하며 상세 화면의 영역별 진행 표시는 유지한다.
